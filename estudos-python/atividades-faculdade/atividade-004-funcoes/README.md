# Atividade 004 - Funções em Python

Exercícios desenvolvidos para praticar definição e chamada de funções em Python.

## Exercícios

1. Manipulação de listas
2. Contagem de caracteres
3. Fatorial recursivo
4. Sequência de Fibonacci
5. Verificação de palíndromo
6. Ordenação com função lambda
7. Substituição de vogais
8. Conversão de Celsius para Fahrenheit
9. Jogo de adivinhação

## Conceitos praticados

- Funções, parâmetros e retorno
- Listas e dicionários
- Laços de repetição e condicionais
- Recursividade
- Strings e métodos de texto
- Funções lambda e ordenação
- Entrada e saída de dados
- Módulo `random`
