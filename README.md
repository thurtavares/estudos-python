# Estudos em Python

Repositório de exercícios desenvolvidos durante meus estudos de Ciência da Computação, com foco em lógica de programação e fundamentos da linguagem Python.

## Organização

- `atividades-faculdade/aula-01/`: exercícios introdutórios com variáveis, entradas e cálculos.
- `atividades-faculdade/aula-02-exercicios/`: exercícios com operadores e condicionais.
- `atividades-faculdade/aula-02-atividades/`: atividades de operações matemáticas, comparações, médias e frequência.
- `exercicios-individuais/`: prática de condicionais, repetições, listas e funções.

## Tecnologias

- Python 3
- Visual Studio Code

## Como executar

Com Python 3 instalado, abra o terminal na pasta do exercício e execute:

```bash
python nome_do_arquivo.py
```

## Observações

Os exercícios preservam minha implementação original. Foram realizados apenas ajustes pontuais para corrigir um cálculo de frequência e substituir dados pessoais de exemplo antes da publicação.
