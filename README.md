# Estudos em Python

Repositório de exercícios desenvolvidos durante meus estudos de Ciência da Computação, com foco em lógica de programação, algoritmos e fundamentos da linguagem Python.

O objetivo é colocar em prática os conhecimentos adquiridos durante a graduação, documentando minha evolução por meio de exercícios acadêmicos e atividades individuais.

## Organização

- `atividades-faculdade/aula-01/`: exercícios introdutórios com variáveis, entradas e cálculos.
- `atividades-faculdade/aula-02-exercicios/`: exercícios com operadores e estruturas condicionais.
- `atividades-faculdade/aula-02-atividades/`: atividades envolvendo operações matemáticas, comparações, médias e frequência.
- `atividades-faculdade/revisao-p1/`: exercícios de revisão para a primeira avaliação, com aplicação de conceitos fundamentais de Python.
- `exercicios-individuais/`: prática de condicionais, estruturas de repetição, listas e operações matemáticas.
- `exercicios-individuais/funcoes/`: exercícios envolvendo funções, parâmetros, argumentos, valores de retorno, funções aninhadas e expressões lambda.

## Conteúdos Abordados

- Variáveis e tipos de dados
- Operadores aritméticos, relacionais e lógicos
- Entrada e saída de dados
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Manipulação e ordenação de listas
- Funções definidas pelo usuário (`def`)
- Parâmetros e argumentos
- Valores de retorno (`return`)
- Parâmetros com valores padrão
- Retorno de múltiplos valores
- Funções aninhadas
- Expressões lambda
- Filtragem de listas com `filter()`
- Documentação de funções com docstrings

## Tecnologias

- Python 3
- Visual Studio Code

## Como executar

Com Python 3 instalado, abra o terminal na pasta do exercício e execute:

```bash
python nome_do_arquivo.py
```

Os exercícios podem ser executados individualmente, de acordo com o conteúdo estudado.

Este repositório reúne atualmente **44 exercícios em Python**, desenvolvidos durante atividades acadêmicas e práticas individuais.
